# Simple Calculator

### Collaborators
- Alex
- Yentl

### Description of the project/program
This project is a simple calculator developed by Alex and Yentl as part of a school assignment.

The calculator allows users to perform basic mathematical operations, such as:
- Addition (+)

The goal of this project is to practise programming skills and learn how to work together on a software project.

### How to install and use the project/program

**Installation:**
1. Download or clone this repository.
2. Open the project folder.
3. Run the main program 

**Usage:**
1. Start the calculator.
2. Enter the numbers you want to calculate with.
3. View the result.
